- Vitest + jsdom + Testing Library + MSW (`vitest run`).
- Zero runtime repo imports: the web talks to `@runwire/server` over HTTP. `import type`
  from `@runwire/core` is fine for DTO shapes.

# Checks

```sh
cd packages/web
bun run test        # vitest run
bun run typecheck   # tsc -b --noEmit
bun run build       # vite build — catches route/asset regressions
```

# Tests

- Network is MSW: `src/mocks/handlers.ts` + `src/mocks/node.ts`, registered with
  `onUnhandledRequest: 'error'` — a new fetch without a handler fails the suite. Add a
  handler when you add an endpoint.
- Hooks/queries: `renderHook` + a fresh `QueryClient` with `retry: false`.
- Components: role/text queries over test ids.
- jsdom lacks `matchMedia`; the stub lives in `src/test/setup.ts` (needed by the
  router's `ThemeProvider`).
