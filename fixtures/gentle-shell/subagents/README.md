# Subagents

Parent, child and task ledger prove full linkage, depth, spawn call identity and
machine initiation. Ledger tokens, cost, turns and toolCalls are deliberately
987654321: none may enter a bundle or replace the child's own JSONL metrics.

Two children pin the two spawn-linkage sources. The first resolves from its
parent's `subagent_run` `toolResult` (`details.gentleAgents.taskId`), silently.
The second's toolResult carries no identity; it links only through the parent's
`gentle-pi.review-reminder-receipt/v1` custom entry (`source: subagent`), so it
must also report an info `receipt-spawn-link` with a count and no receipt text.
