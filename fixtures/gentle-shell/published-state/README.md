# Published state

A Gentle Shell 4.x `gentle-agents.published-state` custom entry carries the
orchestrator's state, with `state` (prose), `ownerReply` and the alias ids all
present in the fixture. The allowlist projects the bounded marker only —
`schema`, `recordedAt`, `authority`, `source` and `aliases` as presence — so the
session imports as a session with a `custom` harness step and none of that
payload text ever reaches a bundle.

The same session holds a `gentle-pi.exploration-budget` `custom_message` (S3c):
`customType` and `display` survive; `content` and `details` stay unread. Both
extension entries are the only reason this case has no tokens, model or tools.
